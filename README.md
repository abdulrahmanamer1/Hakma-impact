# HIKMA IMPACT v5

منصة HIKMA IMPACT لإدارة الأثر، المبادرات، والأداء التطوعي.

## التجربة العامة
- موقع عام للزائر.
- الأخبار، الإداريون، المبادرات، اللجان، الفعاليات، الأثر، المعرض، الشركاء.
- بحث شامل.
- رابط الانضمام الرسمي إلى Telegram: https://t.me/Hikmaht_bot
- Dark / Light Mode.
- PWA.
- API عامة لمؤشرات الأثر.

## مركز الإدارة
- إدارة الأعضاء والإداريين واللجان والمبادرات والمهام والحضور والتقييمات.
- مركز الأخبار والنشر.
- الفعاليات والمعرض والشركاء.
- الإشعارات.
- الموافقات ومركز القرار.
- الأهداف والتحليلات.
- الرؤى الذكية ومركز المخاطر.
- سجل العمليات ومركز الأمن والنسخ الاحتياطي.
- QR للمبادرات والحضور.
- شهادة مشاركة قابلة للطباعة/الحفظ PDF من المتصفح.

## التشغيل
```bash
pip install -r requirements.txt
export HIKMA_SECRET_KEY='change-this'
export HIKMA_OWNER_PASSWORD='set-a-strong-password'
python app.py
```

ثم افتح `http://localhost:5000`.
