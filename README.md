# HIKMA IMPACT — Cinematic Operations v8

منصة HIKMA IMPACT لإدارة الأثر، المبادرات، والأداء التطوعي.

## أهم ما في هذه النسخة

- واجهة زائر سينمائية متعددة المستويات مع Swipe للموبايل.
- أخبار متقدمة: خبر مميز، تصنيفات، بحث، وجدولة نشر.
- خريطة أثر عامة مع حالات: أثر موثق / قريبًا / مخطط.
- خريطة مستقلة لكل مبادرة عند إدخال الإحداثيات.
- زر انضمام قابل للتحكم من الإدارة: إظهار/إخفاء، النص، الأيقونة، الرابط، ومكان الظهور.
- بث مباشر داخل HIKMA IMPACT عبر WebRTC مع خيار ربط بث خارجي.
- غرفة بث داخلية للمسؤولين والمشاهدة العامة من نفس المنصة.
- أرشيف جلسات البث.
- استوديو شهادات وتكريم: الاسم + المبادرة + التاريخ، مع شعارات الفريق/الجامعة، رقم شهادة، QR تحقق، وطباعة/حفظ PDF.
- صفحة تحقق عامة من الشهادة.
- صلاحية مستقلة للشهادات ضمن مصفوفة الصلاحيات.
- Dark / Light Mode.
- إدارة القوائم والأقسام والمظهر والهوية.
- نسخ احتياطي موسع يشمل الجداول الجديدة.

## البث الداخلي

البث الداخلي يستخدم WebRTC من المتصفح مباشرة. يحتاج الموقع إلى HTTPS للوصول إلى الكاميرا والمايك، وهو مناسب للنسخة التشغيلية الأولى. لرفع الاعتمادية عبر شبكات الهاتف والراوترات المختلفة، يمكن إضافة TURN server من إعدادات البنية التحتية لاحقًا.

## التشغيل

```bash
pip install -r requirements.txt
python app.py
```

على Render استخدم Gunicorn وفق إعدادات المشروع الحالية.

غيّر `HIKMA_SECRET_KEY` و`HIKMA_OWNER_PASSWORD` في متغيرات البيئة قبل الإنتاج.

## V11 — حماية البيانات والاستقرار

- يدعم `HIKMA_DATA_DIR` لتحديد مكان دائم لقاعدة البيانات.
- على Render يجب ربط Persistent Disk بمسار مثل `/data` ثم ضبط:
  `HIKMA_DATA_DIR=/data`
- SQLite يعمل مع WAL وbusy timeout لتقليل مشاكل التزامن.
- استيراد النسخ الاحتياطية أصبح داخل Transaction واحدة؛ إذا فشل الاستيراد يتم Rollback ولا تُحذف البيانات الحالية.
- النسخة الاحتياطية تحتوي على `version` و`created_at` وتدعم استرجاع النسخ القديمة بشكل أكثر مرونة.
