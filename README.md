# HIKMA IMPACT v3

Flask + SQLite web app for Hikma Student Team.

## أهم التحديثات
- الصفحة الرئيسية `/` هي الصفحة الافتراضية.
- تصميم RTL حديث ومتجاوب بدون روابط HTML زرقاء افتراضية.
- أخبار بشكل بطاقات تشبه منشورات السوشيال ميديا.
- رفع عدة صور للخبر مباشرة من الجهاز.
- رفع صورة شخصية للعضو والإداري مباشرة.
- رفع عدة صور للمبادرة/الفعالية مباشرة.
- مركز تحكم للإدارة.
- إنشاء حسابات إداريين من داخل الموقع.
- حساب المالك يتم إنشاؤه تلقائياً عند أول تشغيل.
- نسخ احتياطية/قاعدة بيانات SQLite محلية.
