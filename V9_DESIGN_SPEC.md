# AHVT v9 — Design Direction

- Arabic-first institutional identity.
- No swipe/level navigation.
- Homepage is a concise cinematic introduction, not a catalog of every feature.
- Full navigation lives in the top menu.
- Admin login is a quiet link in the footer, not a public hero button.
- Join button is compact and configurable by administrators.
- News, impact map, live, initiatives, administrators and events have dedicated pages.
- Each initiative can own its own impact-map location.
- Impact map supports completed, planned and upcoming locations.
- Live can be internal or connected to an external provider.
- Certificate Studio is part of the management experience.
- Dark/Light is a user preference.
- Impact statistics are represented by a circular wheel/donut plus detail bars.
