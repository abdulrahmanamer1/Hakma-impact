# AHVT V37

## Honor gallery and academy file completion
- Added permission-controlled deletion for individual honor-list gallery images, including cleanup of the stored file.
- Honor galleries now support true per-image management rather than only append-only uploads.
- Academy lesson resources now accept common document formats (PDF, DOC/DOCX, PPT/PPTX, XLS/XLSX) in addition to images and video.
- Academy resource files are stored in the same persistent upload area and are recorded in the academy resource table.
- Payment proof workflow remains restricted to safe image/PDF formats and keeps owner/admin review states.
- Preserved V36 permission hardening and certificate/card verification improvements.
